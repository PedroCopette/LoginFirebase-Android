# LoginFirebase - Android

Aplicativo Android desenvolvido para a disciplina de Programação para Dispositivos Móveis.

## Funcionalidades

O aplicativo possui três telas:

- **Login:** campos de e-mail e senha, com botão para entrar e cadastrar.
- **Registration:** campos de nome, e-mail e senha, com botões para registrar e voltar.
- **Dashboard:** tela principal com informações e layout organizado.

## Tecnologias

- Kotlin
- Android Studio
- Jetpack Compose
